# Hendro Paulus — Portfolio

A lightweight personal portfolio built with plain HTML, CSS, JavaScript, and Bootstrap CDN.

## Structure

```text
portfolio/
├── index.html
├── assets/
│   ├── css/
│   │   └── style.css
│   ├── js/
│   │   └── main.js
│   ├── img/
│   └── projects/
└── README.md
```

## Run locally

No build step is required.

You can:

1. Open `index.html` directly in your browser, or
2. Use VS Code Live Server.

## Publish for free

### GitHub Pages
Push this folder to a GitHub repository, then enable **Settings → Pages → Deploy from branch**.

### Cloudflare Pages
Connect your GitHub repository to Cloudflare Pages.

For this static portfolio:
- Framework preset: **None**
- Build command: leave empty
- Output directory: `/`

## Personalize

Important places to edit:

- `index.html`
  - email
  - GitHub URL
  - phone number
  - experience
  - selected projects
- `assets/css/style.css`
  - theme and styling
- `assets/js/main.js`
  - theme toggle and scroll interactions
